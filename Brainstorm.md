## 2. Regional Behavioral Directives\
The AI must map its design, performance, and legal recommendations based on the chosen *Target Region Code*:\
\
### 2.1 Region: ZA (South Africa / African Hubs)\
*   **UX Execution Rules:** Strict mobile-first responsiveness. Build layout sheets using minimal media assets or optimize images heavily for fast loading on varied mobile connections.\
*   **Trust Anchors:** Prioritize personal accountability features (direct WhatsApp integrations, face portrait layouts) and local business registry markers.\
*   **Aesthetic Notes:** Grounded, high-trust colors punctuated by sharp, rich African landscape-inspired luxury tones (Emerald, Ochre, Gold).\
\
### 2.2 Region: EU (Europe / High-Compliance Hubs)\
*   **UX Execution Rules:** Pixel-perfect alignment using tight structural grids. Layout performance must prioritize absolute layout stability (zero CLS).\
*   **Trust Anchors:** Rigid compliance engineering. Prominently map empty semantic placeholder containers for native cookie routing, an easily accessible Impressum, and strict GDPR/DSGVO data-privacy compliance links.\
*   **Aesthetic Notes:** Minimalist, clean, structural layout. Deep neutrals combined with a singular high-precision accent color (Slate, Industrial Blues, Tech-Teal).\
\
### 2.3 Region: LATAM (Latin America / High-Velocity Hubs)\
*   **UX Execution Rules:** High focus on dynamic mobile viewing, micro-interactions, and swift, smooth rendering speeds for heavy image/card assets.\
*   **Trust Anchors:** Social-proof dominance. Heavy use of partner logo belts, visible user review indicators, and immediate, lively social ecosystem links.\
*   **Aesthetic Notes:** High energy, modern layouts featuring bold typography, layered card aesthetics, and active, fluid GSAP layout entrance transitions.\
\
### 2.4 Region: US (North America / Conversion-First Hubs)\
*   **UX Execution Rules:** High-conversion interface formatting. Above-the-fold value statements must load immediately with bold call-to-action buttons.\
*   **Trust Anchors:** Data-backed authority markers (e.g., "50+ Projects Completed", "Est. 15 Years").\
*   **Aesthetic Notes:** Bold, clean typography, direct messaging, stark spacing, and layout lines designed to guide the eye directly down the sales funnel.\
